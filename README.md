# RECRUTA — Recrutamento & Seleção

  

Site institucional desenvolvido para a RECRUTA, uma empresa fictícia de consultoria especializada em Recrutamento e Seleção estratégica.

  

O projeto foi desenvolvido com foco em uma experiência profissional, moderna e responsiva, apresentando os serviços, diferenciais, metodologia e canais de contato da empresa.

---

  

## 📌 Sobre o projeto

  

A RECRUTA é uma empresa fictícia criada para este projeto, com o objetivo de desenvolver uma presença digital institucional para uma consultoria de Recrutamento e Seleção.

  

A proposta foi criar uma interface moderna, profissional e responsiva, organizando as informações da empresa de forma estratégica e proporcionando uma experiência de navegação clara e intuitiva.

  

---

  

## 🚀 Funcionalidades

  

- Layout responsivo para desktop, tablet e celular

- Navegação por seções

- Menu responsivo para dispositivos móveis

- Botões de contato via WhatsApp

- Animações suaves de entrada dos elementos

- Efeitos de interação em botões e cards

- Efeito de zoom suave nas imagens

- Linha do tempo visual para apresentação da metodologia

- Destaque visual para a seção atual do menu

- Rolagem suave entre as seções

- Estrutura otimizada para diferentes tamanhos de tela

## 🎨 Interface

  

A identidade visual utiliza tons de azul, azul-claro e branco, combinando elementos institucionais com uma apresentação mais moderna.

  

O conteúdo está organizado nas seguintes seções:

  

- Home

- Desafio

- Sobre

- Soluções

- Por que RECRUTA?

- Metodologia

- Resultados

- Contato

  

## 📱 Responsividade

  

O layout foi desenvolvido para diferentes tamanhos de tela, com adaptações específicas para desktop, tablet e dispositivos móveis.
